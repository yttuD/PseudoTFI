# Bundled web fonts

These Latin-subset WOFF2 files were copied from this application's previously generated Next.js font cache so that production builds do not need to contact Google Fonts. They preserve the typography already in use; no glyph outlines were changed.

- `inter-latin.woff2`: Inter by Rasmus Andersson, [official source and SIL Open Font License](https://github.com/rsms/inter).
- `jetbrains-mono-latin.woff2`: JetBrains Mono by JetBrains, [official source and SIL Open Font License 1.1](https://github.com/JetBrains/JetBrainsMono).

Both fonts are distributed under the SIL Open Font License 1.1. Keep this notice and the upstream license terms with the font files when redistributing them. The files contain the Latin character range used by the Spanish, Portuguese and English beta UI; if another script is supported later, add its subset explicitly.
