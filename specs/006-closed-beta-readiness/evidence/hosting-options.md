# Opciones de hosting para la beta no comercial de Rendo — 2026-09-30

La base de datos continúa en el Supabase exclusivo de Rendo. Esta comparación se refiere únicamente a la API NestJS; la web Next.js ya tiene como destino previsto Vercel. Ninguna alternativa fue desplegada ni probada con esta API todavía.

| Opción para la API | Costo de entrada documentado | Restricción relevante | Encaje en Rendo |
|---|---|---|---|
| Otra cuenta Railway ya habilitada | Depende del plan/crédito real de esa cuenta. Tras la prueba, Free incluye US$1 de crédito mensual; Hobby cuesta US$5/mes. | El crédito Free puede agotarse; cambiar GitHub no reinicia una prueba de Railway. | Menos adaptación para un servidor NestJS persistente, pero comprobar plan y presupuesto antes de conectar el servicio. [Railway Free Trial](https://docs.railway.com/pricing/free-trial), [Railway Plans](https://docs.railway.com/pricing/plans). |
| Vercel Hobby, segundo proyecto para la API | Plan gratuito **solo si el uso es personal/no comercial** y dentro de cuotas. | Vercel ejecuta NestJS como una Function, no como un proceso permanentemente activo; validar arranque, tamaño del bundle (límite de 250 MB) y cualquier trabajo de fondo. Aunque la beta actual no cobra, Rendo contempla comercialización futura; no asumir que Hobby admite este uso sin aclarar su finalidad con Vercel. | Buena opción técnica por soporte oficial de NestJS y una sola cuenta para web/API, pero elegibilidad del plan y compatibilidad real son dos gates distintos. [Vercel NestJS](https://vercel.com/kb/guide/ship-a-nestjs-app-on-vercel), [Hobby](https://vercel.com/docs/plans/hobby), [Fair Use](https://vercel.com/docs/limits/fair-use-guidelines). |
| Render Free | Web Service Node.js sin costo inicial documentado; 750 horas de instancia al mes por workspace. | Se duerme tras 15 minutos sin tráfico; la primera solicitud puede tardar alrededor de un minuto. Render indica que Free no es para aplicaciones de producción. | Viable para una prueba manual tolerante a esperas, pero mala experiencia para testers que reportan tiempos y errores. [Render Free](https://render.com/docs/free). |
| Koyeb Free | Una instancia web gratuita por organización: 512 MB de RAM, 0,1 vCPU. | Escala a cero después de una hora sin tráfico; recursos muy ajustados para verificar toda la API NestJS sin antes medir consumo. | Alternativa secundaria; no asumir que la compilación/arranque de Rendo caben en ese límite. [Koyeb Instances](https://www.koyeb.com/docs/reference/instances), [Scale-to-Zero](https://www.koyeb.com/docs/run-and-scale/scale-to-zero). |
| Google Cloud Run | Tiene cuota gratuita mensual basada en uso. | Requiere proyecto de Google Cloud con facturación habilitada y puede generar cargos si se excede la cuota o hay tráfico/egreso facturable. Requiere empaquetado y configuración adicionales. | Técnicamente viable, pero más trabajo y control de costos para esta beta pequeña. [Cloud Run pricing](https://cloud.google.com/run/pricing), [Node.js quickstart](https://docs.cloud.google.com/run/docs/quickstarts/build-and-deploy/deploy-nodejs-service). |

**Recomendación condicionada**: si Carlos necesita costo cero para unos pocos testers y acepta que la API tarde alrededor de un minuto en despertar, Render Free es la opción más directa sin presumir elegibilidad comercial de Vercel Hobby. Si necesita una beta con respuestas más consistentes, usar la otra cuenta Railway ya habilitada, verificando primero plan/crédito. Vercel para web+API se puede probar si Vercel confirma que este uso concreto cumple Hobby; después hay que validar `/health/ready`, CORS, Auth, permisos, almacenamiento, invitaciones y tamaño del bundle. No crear cuentas nuevas únicamente para repetir pruebas gratuitas.
